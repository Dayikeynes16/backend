# La isla en la web, y la agenda como fuente de avisos — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Una sola «isla» de avisos en la web (la misma del hub), con la agenda como fuente de avisos (recordatorios vencidos y tareas asignadas), y los avisos entregándose en vivo de verdad.

**Architecture:** Backend: dos notificaciones nuevas de agenda, un comando por minuto que avisa los recordatorios vencidos, un `AgendaReminderNotifier` que centraliza destinatario/envío/cierre, y en todas las notificaciones broadcast síncrono (`onConnection('sync')`) + `broadcastType()` + guardia por destinatario. Frontend: port del motor y la isla del hub (`carniceria-hub/src/renderer`) a Inertia/Ziggy/Echo; sustituye a `NotificationBell` y `AgendaBell`.

**Tech Stack:** Laravel 13, PHPUnit (PostgreSQL), Vue 3 `<script setup>` + Inertia 2 + Ziggy, Laravel Echo (Reverb), Tailwind 3, Vitest (`tests/js`, entorno `node`).

**Spec:** `docs/superpowers/specs/2026-09-24-isla-web-design.md` (manda sobre este plan si discrepan).

```php
class DispatchAgendaRemindersCommand extends Command
{
    protected $signature = 'agenda:dispatch-reminders';

    protected $description = 'Avisa (isla) los recordatorios de agenda que ya vencieron';

    public function handle(AgendaReminderNotifier $notifier): int
    {
        // Sin `tenant` enlazado TenantScope no filtra (como CheckDevicesCommand).
        // No usar withoutGlobalScopes(): quitaría también SoftDeletes.
        AgendaItem::query()
            ->active()
            ->whereNotNull('remind_at')
            ->where('remind_at', '<=', now())
            ->whereNull('reminder_seen_at')
            ->whereNull('reminder_notified_at')
            ->orderBy('remind_at')
            ->each(fn (AgendaItem $item) => $notifier->remind($item));

        return self::SUCCESS;
    }
}
```
